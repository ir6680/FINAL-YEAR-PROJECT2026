# LaTeX Source — DeFi AI Assistant IEEE Paper

This is a faithful LaTeX conversion of `DeFi_AI_Assistant_IEEE_Paper_v2.docx`.
The scientific content (all metrics, statistics, table values, confusion-matrix
counts, p-values, confidence intervals, model names, and equations) is preserved
exactly as in the source document. This was a format conversion, not a rewrite.

## How to compile (Overleaf — recommended)

1. Upload the entire folder (or the ZIP) to a new Overleaf project.
2. Set the main document to `main.tex`.
3. Set the compiler to **pdfLaTeX** (Menu > Compiler > pdfLaTeX).
4. Compile. The bibliography is BibTeX; Overleaf runs the
   pdfLaTeX -> BibTeX -> pdfLaTeX -> pdfLaTeX sequence automatically.

## How to compile (local command line)

```
pdflatex main
bibtex   main
pdflatex main
pdflatex main
```

Requires a TeX distribution that includes the `IEEEtran` document class and
`IEEEtran.bst` (TeX Live `texlive-publishers`, or MiKTeX, both ship it).

## Notes for the author (please review before submitting)

1. **Author identity — 4 placeholders to fill.** `main.tex` contains four
   `[REQUIRES USER INPUT]` markers in the author block: (i) author name(s),
   (ii) roll number(s), (iii) session, and (iv) supervisor — each left
   unfilled in the source document. Replace each with the real value. The
   affiliation line (Department of Information Sciences, University of
   Education, Lahore — Vehari Campus, Punjab, Pakistan) is carried over from
   the source; confirm it is correct.

2. **Document class.** The paper uses
   `\documentclass[conference,onecolumn,letterpaper]{IEEEtran}` — IEEE single
   column, as requested. To switch to the standard IEEE two-column conference
   layout, remove `onecolumn`. (Some tables are sized for the single-column
   width and may need their `\resizebox`/column widths revisited if you change
   this.)

3. **Tables are real LaTeX, kept inline.** Every table is a genuine
   `tabular`/`tabularx` (not an image), placed inline in its section file rather
   than in a separate `tables/` directory — this keeps each table next to the
   prose that references it and is the more reliable layout. Tables I–XI use
   `booktabs`; Table XI spans the full text width via `table*`.

4. **All 8 figures included.** Figure 4 (`fig_confusion_all.png`) contains the
   confusion matrices of **all four** models (MLP, logistic regression, random
   forest, decision tree) as separately labeled panels (a)–(d), not only the
   deployed model's.

5. **Cross-references are automatic.** Figure, table, equation, and section
   numbers are generated by LaTeX via `\label`/`\ref`/`\eqref`; none are
   hard-coded. Reference numbering [1]–[22] is locked to the source order by an
   ordered `\nocite` in `main.tex` (IEEEtran.bst sorts by citation order).

## Validation performed

The six section files were compiled and rendered locally to verify content,
math, tables, cross-references, and citations: clean compile with zero errors,
zero undefined references, zero undefined citations, zero multiply-defined
labels, and all 22 bibliography entries resolving. Because the `IEEEtran` class
is not installed in the local sandbox, validation used an equivalent
`article`-class wrapper with the same packages and macros; the shipped project
targets `IEEEtran`, which is present on Overleaf. Under `IEEEtran` the section
and subsection numbers render in the IEEE style (e.g. III, IV-D, Section V)
rather than the Arabic numbers a local `article`-class preview would show — the
cross-references resolve correctly either way.
