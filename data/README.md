# Data

## Included Files

- `raw/personal_finance_tracker_dataset.csv`: raw dataset used by the notebook.
- `processed/classification_dataset_with_risk_labels.csv`: classifier features with generated risk labels.
- `processed/clustered_dataset_with_risk_labels.csv`: clustering features with cluster and risk labels.

## Expected Raw File

The notebook expects:

```text
data/raw/personal_finance_tracker_dataset.csv
```

## Format

CSV with a header row. The raw file has 3000 rows and 28 columns in this package.
