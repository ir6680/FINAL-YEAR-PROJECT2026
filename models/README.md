This file is the final saved project bundle from the notebook. It contains the selected Multilayer Perceptron classifier pipeline, KMeans cluster artifacts, feature contracts, risk mapping, and metadata used for inference.

The model bundle is generated by the final notebook after fitting KMeans and the selected MLP classifier on the full dataset.
