# System Flow

1. Load trained model bundle and raw personal-finance dataset.
2. Correct and derive financial features.
3. Build classifier input using the saved feature contract.
4. Predict ML risk class and confidence.
5. Infer cluster risk and detect drift.
6. Apply finance guardrails and final risk policy.
7. Generate portfolio allocation and recommendation text.
8. Run portfolio simulation.
9. Produce explainability outputs, report rows, PDF bytes, and audit receipt.
